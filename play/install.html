Reactor Defense

Install it to your home screen — it runs fullscreen like a normal app, and works with no signal.

▶ Open the game

iPhone / iPad

  1. Open this page in Safari. It has to be Safari — Chrome and Firefox on iPhone can't install it.
  2. Tap the Share button (the square with an arrow, at the bottom).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. A Reactor Defense icon appears on your home screen.
  5. Play from that icon from now on — see the warning below.

Android

  1. Open this page in Chrome.
  2. Tap the ⋮ menu → Add to Home screen (or tap the install prompt if it appears).
  3. Confirm, then launch from the new icon.
Important — always play from the home screen icon.
The icon version and the Safari tab version keep separate save files. If you play in the browser tab sometimes and the icon other times, it will look like your progress vanished. Install first, then use the icon every time.
Already been playing an older link? That progress will not carry over on its own — saves are tied to the exact web address. In your old copy open ⚙ Settings → 💾 Save Backup → Export, save the code, then open the new icon version and use Import.
Keeping your progress safe. Your save lives on your device, not on a server. Don't delete the icon or clear Safari website data. Exporting a backup code now and then is the only real insurance — ⚙ Settings → 💾 Save Backup → Export.

Updates

New versions arrive on their own. Open the game, close it, and open it again — the second launch runs the new build. Your progress is untouched by updates.
